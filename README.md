# ALOUD

Персональная студия чтения вслух для задания 1 устной части ЕГЭ по английскому языку (формат 2026). Сайт работает локально, без сборки и без серверной базы данных.

## Запуск

1. Установите [Node.js](https://nodejs.org) LTS, если его ещё нет.
2. Дважды щёлкните **`Запустить ALOUD.bat`**.
3. Браузер откроет `http://localhost:4173`.

Или вручную:

```bash
npm start
```

Локальный сервер нужен для ES-модулей, микрофона и распознавания речи: браузер разрешает эти функции только на `localhost` или HTTPS. Просто открыть `index.html` двойным щелчком недостаточно.

Остановить сервер: `Ctrl+C` в окне консоли.

## Онлайн-версия

Сайт опубликован на GitHub Pages: `https://kins08.github.io/aloud-ege/` (репозиторий [`aloud-ege`](https://github.com/kins08/aloud-ege)).

- Открытие по ссылке работает без Node и без локального сервера: микрофон и распознавание речи доступны по HTTPS.
- Обновление — обычный цикл: правите файлы в этой папке, затем `git add -A`, `git commit`, `git push origin main`. Pages перезапустится сам, примерно за минуту.
- Данные не общие: `localhost:4173` и домен Pages — разные сайты для браузера, поэтому история проверок у каждой версии своя. Перенести её можно так: **Настройки → Скачать резервную копию** на одной версии, **Настройки → Загрузить из копии** на другой.

## Что внутри

- **Обзор** — паспорт задания, критерий ФИПИ, быстрый старт и последняя динамика.
- **Проверка чтения** — выбор текста, подготовка 1:30, запись 1:30, таймер, живая волна микрофона, распознавание речи, редактирование транскрипта.
- **Разбор** — предварительный вердикт 1/0, метрики темпа и пауз, подсветка слов с ошибками, план исправлений, аудиозапись, сертификат при вердикте «1 балл».
- **Библиотека текстов** — 10 оригинальных тренировочных текстов формата ЕГЭ (155–160 слов), слова-ловушки, образцовые разборы и импорт своих текстов из открытого банка ФИПИ.
- **Частые ошибки** — слова с IPA, минимальные пары, привычки произношения и поиск по словарю.
- **Как не ошибаться** — ударение, окончания `-ed`/`-s`, буквенные модели, имена, числительные и мини-тесты.
- **Единство речи** — смысловые группы, паузы, фразовое ударение, слабые формы, интонация, связки и темп.
- **Прогресс** — история попыток, график оценок, слабые зоны.
- **Источники и метод** — формулировки критериев, официальные ссылки и логика автоматической проверки.
- **Настройки** — имя для сертификата, вариант английского, необязательный AI-наставник, экспорт и удаление данных.

## AI-наставник (необязательно)

Локальный движок проверяет чтение без интернета и без API-ключа. Дополнительный разбор от языковой модели включается в **Настройках**:

- OpenAI-совместимый провайдер или Anthropic;
- Base URL, модель и API-ключ;
- ключ хранится только в `localStorage` этого браузера, отправляется напрямую провайдеру и **не попадает в экспорт**;
- провайдеру уходит только текстовая сводка разбора, без аудио.

Без ключа сайт полностью работоспособен.

## Официальные тексты ФИПИ

Тексты ФИПИ не копируются в проект. В библиотеке — оригинальные тексты того же формата и объёма. Официальные задания доступны в [открытом банке ФИПИ](https://ege.fipi.ru/bank/): английский язык → устная часть → чтение текста вслух. Любой такой текст можно вставить через **Библиотека → Свой текст** — он сохранится только на этом устройстве.

## Данные и приватность

- Отчёты, свои тексты, чек-лист и настройки хранятся в `localStorage`.
- История ограничена 30 отчётами.
- Аудиозапись живёт в памяти вкладки и исчезает после перезагрузки.
- Экспорт JSON не содержит API-ключ; импорт из копии добавляет отчёты и тексты, не стирая существующие.
- В открытом репозитории лежат только код и учебные тексты — ни имени, ни отчётов, ни ключей там нет.
- Сайт не является официальным сервисом ФИПИ и не выставляет экзаменационный балл.

## Оценка

Автоматическая оценка приближена к логике критерия ФИПИ, но опирается на распознанную речь и аудиометрию. Распознавание может ошибаться, поэтому транскрипт можно править перед разбором. Это инструмент практики, а не замена экзаменатору.
